Everything in this folder is **placeholder data**, generated to preview what the real Google Form → Excel export will look like once actual testers respond. It is **not** evidence of real user onboarding and does not count toward any user-growth requirement.

- Emails: `test01@example.com` … (`example.com` is the reserved domain that's never a real deliverable address)
- Wallets: `GAAA...0001` … (not a valid Stellar strkey)
- Every feedback string is prefixed `[SAMPLE]`
- The `.xlsx` file's first sheet is a disclaimer, before the data sheet

Once the real Google Form (see [`../USER_ONBOARDING_FORM.md`](../USER_ONBOARDING_FORM.md)) has genuine responses, replace the link in the main README with the real exported sheet — don't extend this file with real rows.
