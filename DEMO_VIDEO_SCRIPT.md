## 🎥 RECORDING SETUP

### Tools to Use (Choose One)
1. **OBS Studio** (Free) - Recommended
   - Download: https://obsproject.com
   - Install: Takes 2 minutes
   - Setup: Very simple

2. **Windows 10 Game Bar**
   - Press: Windows + G
   - Built-in, no install needed

3. **ScreenFlow** (Mac)
4. **Camtasia** (Paid, pro quality)

### OBS Quick Setup
1. Install OBS Studio
2. Open OBS
3. Click "+" under Sources → Add "Display Capture"
4. Select your monitor
5. Click "Start Recording"
6. Walk through the demo
7. Click "Stop Recording"
8. Find video in Videos folder

### Recording Settings
- Resolution: 1920x1080 (Full HD)
- FPS: 30 (smooth but smaller file)
- Bitrate: 5000 kbps (good quality)
- File format: MP4

## 💡 DEMO TIPS

- **Practice first**: Walk through once before recording
- **Speak clearly**: Audio quality matters
- **Go slow**: Give viewers time to understand
- **Show everything**: From wallet → deposit → confirm → complete
- **Highlight security**: Mention smart contract guarantees
- **Show real app**: Use actual live app, not mockups
- **Be authentic**: Show real workflow, don't skip steps
